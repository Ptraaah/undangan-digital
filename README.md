# undangan-digital

Template undangan pernikahan digital satu file, gratis, tinggal ganti isi dan bagikan tautannya. Dibangun untuk pasangan Indonesia yang ingin undangan cantik tanpa bayar mahal dan tanpa ribet.

## Fitur

- Sampul "Buka Undangan" dengan nama tamu personal dari URL (`?to=Nama+Tamu`)
- Hitung mundur ke hari H
- Kartu Akad dan Resepsi dengan tombol lokasi Google Maps
- Galeri foto
- Amplop digital dengan tombol salin nomor rekening
- Konfirmasi kehadiran (RSVP) yang terkirim rapi ke WhatsApp mempelai
- Musik latar opsional, tampil bagus di HP

## Cara pakai

1. Fork atau unduh repo ini.
2. Buka `index.html`, ganti semua isi di blok `CONFIG` pada bagian script: nama mempelai, tanggal, tempat, tautan peta, foto, nomor rekening, dan nomor WhatsApp.
3. Ganti foto galeri dengan URL foto Anda sendiri.
4. Publikasikan gratis: GitHub Pages, Netlify, Cloudflare Pages, atau hosting statis apa pun. Satu file ini saja cukup.
5. Bagikan tautan dengan nama tamu: `https://undangan-anda.example/?to=Bapak+Joko+dan+Keluarga`

## English summary

A free, single-file digital wedding invitation template in Indonesian style: cover screen with personalized guest name, countdown, ceremony and reception cards with map links, photo gallery, digital gift envelope with copy-account-number, and WhatsApp RSVP. Edit the CONFIG block, deploy to any static host, share the link.
